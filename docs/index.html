Document Ops Workflow + GCP Prototype

Built at home to get a better feel for document-heavy finance and commercial ops: extract key fields, classify the document, run a few checks, route edge cases to review and keep an audit trail. I kept the working version local, then added the GCP pieces I would use to take it further.
Current buildWorking locally: FastAPI, Pydantic models, extraction/classification logic, validation + routing, SQLite audit log, Docker/CI and the dashboard.

Not wired up yet: Document AI, Vertex AI, BigQuery, Cloud Run and Apigee. The repo has the config/IaC needed for that next step.
